# Interview

For a user with no reachable source, or to fill a gap the sources leave. Ask in one message, adapted to the period:

1. Which projects did you work on?
2. For each, what is finished, and what changed for the people who use it?
3. What is the one number that shows it: a count, a time, a size, a version?
4. What is next for each?
5. Is there a link, screenshot or file that shows it?

Write the answers into `notes.md` with the user as the source. Ask one follow-up only for a project whose answer has no outcome yet, such as "worked on the API": ask what the API does now that it didn't before.
